OpenAPI quick tester

single-file HTML для тестирования основных эндпоинтов (multipart + JSON)
Auth

Optional: Login (POST) to obtain token

2) Update Tag (PUT /api/v1/tags/{id})

Отправляет JSON в теле с Content-Type: application/json

3) Upload My Avatar (multipart)

Response / Logs
